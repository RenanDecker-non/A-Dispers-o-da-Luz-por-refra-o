## 📚 Sobre o Projeto

Este é um site educacional completo que explora o fascinante fenômeno da **dispersão da luz por refração**. Desenvolvido com HTML, CSS e JavaScript puros, o projeto visa tornar conceitos complexos da óptica física acessíveis e visualmente atraentes.

### 🎯 Objetivos

- 📖 Explicar de forma didática os conceitos de refração e dispersão da luz
- 🧮 Fornecer ferramentas interativas (calculadora da Lei de Snell)
- 🌈 Apresentar aplicações reais: arco-íris, diamantes, aberração cromática
- 📜 Contextualizar historicamente com o experimento de Isaac Newton

---

## 🚀 Funcionalidades

✅ **Design moderno e responsivo** (tema escuro com efeitos visuais)  
✅ **Navegação suave** entre seções com scroll animado  
✅ **Conteúdo completo** sobre dispersão da luz  
✅ **Fórmulas matemáticas** renderizadas com MathJax  
✅ **Tabelas estilizadas** com dados científicos  
✅ **Calculadora interativa** da Lei de Snell-Descartes  
✅ **Menu mobile** responsivo (hambúrguer)  
✅ **Animações de entrada** com Intersection Observer  
✅ **Efeito parallax** sutil no hero
